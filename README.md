# LLM Testing & Agentic Engineering Masterclass

Comprehensive Zero-to-Hero roadmap for the **Senior SDET → AI/Agentic Automation Engineer** transition.

## 📖 Curriculum
The core guide is located here: **[LLM_TESTING_MASTERCLASS.md](LLM_TESTING_MASTERCLASS.md)**

It covers:
- Foundations of LLM & GenAI (Transformers, RAG, Probabilistic Eval)
- Testing Frameworks: **DeepEval**, **Ragas**, **Promptfoo**
- **Agentic Testing** (Self-healing locators per ADR-019)
- **Testing Agents** (Reasoning/Trajectory validation via ReAct)
- **Observability** (OpenTelemetry GenAI spans per ADR-016)

## 🏗️ Standards
This repository is governed by the **7 Laws of QA Automation**.
See **[STANDARDS.md](STANDARDS.md)** for details.

## 🛠️ Usage
- Local LLM: Requires [Ollama](https://ollama.com/) with `llama3.1` and `nomic-embed-text`.
- Vector DB: ChromaDB.
- Python 3.10+
